Дата: 2026-11-08. Корень: `Light_Crypto_Manager/`.

До начала работы корневого Git-репозитория не было. Автор Git уже настроен;
глобальные настройки не изменялись. Создана основная ветка `main`.

Найден один вложенный репозиторий: `src/web/ascon/.git`, ветка `master`,
HEAD `ed24e54` (`improve types for writer.py`). Отслеживаемые файлы не изменены;
неотслеживаемый `__pycache__/` существовал до работы. Вложенный репозиторий сохранён.
Пять его исходных файлов включаются в корневой Git как обычные файлы, а не gitlink:
восстановление базовой версии не требует загрузки подмодуля. Его история остаётся
локальной и включена в резервную копию. Исходная структура каталогов сохранена.

## Сохранение оригинала

До изменений создан `.local-baseline/original-src.tar.gz` со всем исходным `src/`,
включая вложенный Git и архив. Рядом находится `sha256.json` с SHA-256 исходных
файлов. Права каталога — 0700, файлов — 0600. Каталог исключён из Git. Это
незашифрованная локальная копия: не публиковать. Для сверки/восстановления сначала
распаковать в отдельный приватный каталог, не поверх безопасной рабочей версии.

## Минимальные отличия от оригинала

Встроенные значения считаются потенциально реальными секретами; их действительность
не проверялась подключением к чужим сервисам. Значения не включаются в отчёты.

| Файл | Изменение для безопасного коммита |
|---|---|
| `src/web/config.py` | Секрет Flask, URI БД и ключ Ascon заменены обязательными переменными окружения; MQTT host имеет локальное значение по умолчанию, пароль берётся из окружения |
| `src/publisher/mqtt_pub.py` | Ключ Ascon из `ASCON_KEY_HEX`; адрес из `MQTT_HOST`, по умолчанию localhost |
| `src/brocker/mqtt_brocker.py` | Ключ, реквизиты БД из окружения; MQTT host по умолчанию localhost |
| `src/web/app.py` | Пароли начальных пользователей из окружения; удалена печать пароля |
| `src/classifier/iot-test.ipynb` | Удалены сохранённые outputs и execution_count: они содержали фрагменты датасета, сетевые адреса и локальные пути; исходный код ячеек сохранён |
| `.gitignore` | Исключены кеши, окружения, секреты, БД, модели, датасеты, архивы и локальные артефакты |

Требуемые переменные: `FLASK_SECRET_KEY`, `DATABASE_URL` (существующий MSSQL
SQLAlchemy URI), `ASCON_KEY_HEX` (16 байт, 32 hex-символа), `DB_SERVER`, `DB_USER`,
`DB_PASSWORD`, `BOOTSTRAP_ADMIN_PASSWORD`, `BOOTSTRAP_OPERATOR_PASSWORD`,
`BOOTSTRAP_VIEWER_PASSWORD`. MQTT: `MQTT_HOST`, необязательный `MQTT_PASSWORD`
для web. Остальная конфигурация и логика не перерабатывались. Без обязательных
переменных выполнение завершается ошибкой; воспроизводимый запуск — следующий этап.

`src/web/web_mqtt.zip` проверен через чтение ZIP без распаковки: 72 записи,
копии кода, встроенная конфигурация, вложенная `.git` и `.pyc`. Секреты также
присутствуют в архиве. Он сохранён локально, но исключён из истории.
Вложенные `.git`, кеши и служебные каталоги окружения не добавляются в корневой Git.

Проверка до staging: просмотр конфигурационных присваиваний и паролей в исходниках,
поиск подозрительных полей во всех текстовых файлах и членах ZIP, проверка notebook
(включая outputs). Дополнительно выполнено сравнение подготовленных файлов с
выделенными исходными секретами. Это локальная проверка, не доказательство
отсутствия всех возможных секретов. Ни установка пакетов, ни сетевые подключения,
ни запуск Flask/MQTT/БД на этапе 0 не выполнялись.
