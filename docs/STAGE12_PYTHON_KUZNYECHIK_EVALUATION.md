# Python Kuznyechik/MGM evaluation

Upstreams rechecked for Stage12, pinned revisions in reports/candidates.json. [drobotun/gostcrypto](https://github.com/drobotun/gostcrypto):60d5338, MIT, Kuznyechik/Magma but no MGM AEAD API in checked tree. [mosquito/PyGOST](https://github.com/mosquito/pygost):dfa5e69 is old and has no MGM. [ZvonokComGroup/PyGOST](https://github.com/ZvonokComGroup/pygost):b06da69, version5.12/GPL3, contains complete Python MGM and both ciphers. Neither mirror is silently called current official upstream.

Official NEWS/FreeBSD ports indicate5.13. HTTPS archive downloads from official host and FreeBSD cache failed certificate verification in this environment. TLS verification was not disabled;5.13 source behavior is therefore not_verified, not assumed identical to5.12. Source hashes, successful clone pins and download failures are retained. No PyPI package was automatically installed as production-ready.

Checked5.12 supports full Python AEAD without subprocess. A separate strict research wrapper passes all10 RFC7801 round keys/block encrypt/decrypt, RFC9058 A.1.1/A.1.2,31 exact Go cross-checks and93 damaged-tag tests. Keys not recorded. Wrapper enforces bytes, key32/ICN16/MSB0, AAD1024/P4096, no jointly empty P/A, full tag. Raw API has two reproducible validation defects: length limit expressed in bytes rather than RFC bits; Open validates ciphertext including tag and can accept empty P/A when given the internal computed tag. These are isolated upstream API findings, not demonstrated MQTT vulnerabilities; live parser is bounded and AAD nonempty. Research wrapper closes these parameter cases but does not establish timing safety.

Table-indexed S-box/L transforms and Python big-integer GF loops are variable-time; GPL distribution must be assessed separately. This backend is measured only in offline research, not registered or shipped in runtime images. OpenSSL gost-engine af2b7e6/Apache2 has real MGM and native ciphers, but no new Python binding/ABI/ARM build was validated here. EVP adapters would need buffered authenticated finalization before returning plaintext. No claim of FFI safety is inferred from native speed.

Decision: retain verified Go one-shot as compatibility default; use bounded Go worker only by explicit lab configuration after KAT/IPC/E2E. Python is a useful independent research comparator, not selected merely because the application uses Python. ARM and whole-provider constant-time remain unverified for all newly considered choices.
