The complete ordered process-call trace and returned results are compared, along with final states/signals/decisions/transitions. Persisted alternating turn prevents restart/odd batch boundary from changing source scheduling. Full expected/actual data are in golden-release.json; no merely printed PASS proof.

Additional real PG tests: T+10 processed then newly committed T+5→audited late;2workers/one device100 events;4workers/ten devices100 events; rollback before commit leaves no state/marker/dequeue; version activation waits for old batch and seeds all retained sources; new version uses its own rules; retention race preserves unread IDs; lock timeout cannot skip E1; direct state writers cannot lose evidence; retries cannot duplicate decisions/proposals or change guard; unknown/wrong-epoch/feature/model ML rejected without identity; no ML score→no NORMAL; proposals cannot create live commands.

Synthetic scheduling is intentionally hardened relative to the original global-idle-only behavior: maintenance may degrade a silent device while another device is busy, but never overtakes a committed pending real item of the same device. Independent-clock and cross-device tests exercise this contract. This is not a claim that all observed real-run decisions must match despite substantially different processing ages; deterministic equivalence holds for equal inputs/rules/evaluation clocks.
