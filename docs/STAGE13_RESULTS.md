Новая версия заново обнаруживает retained source identities без marker этой версии. История не переписывается; old guards/cooldown semantics сохранены. Source insert не берёт activation lock, поэтому гонка commit/activation не теряет источник. Synthetic stale не обгоняет pending real source своего устройства, но чужой backlog не скрывает stale silent device. ML/security alternation durable; ML всегда research/untrusted, отсутствие ML не NORMAL.

**Безопасность:** Policy DRY_RUN; настоящие crypto commands только manual admin+CSRF через прежний durable Control Worker. Ascon/AES/Kuz crypto/math/keys/nonces/wire format не менялись. Единственное Kuz release дополнение — явный Stage13 test namespace при прежних gates, lab-only сохраняется. Magma отсутствует в live control. Старые volumes/ключи/научные артефакты не используются и не удаляются.

Остаточные ограничения: один serialized worker authority, capacity/retention100000, activation seed/replay cost, bounded input/statement timings, software host only; нет HA/ARM/trusted IDS/production Kuz claim. Между old/new worker бинарниками нет безопасного mixed rollout: остановить old, upgrade, стартовать new. Для последующего RF/IF исследования инфраструктурная обработка улучшена; доказательства label/source/dataset качества и отдельное разрешение на обучение всё ещё необходимы. Автоматического control доверия это не даёт.
