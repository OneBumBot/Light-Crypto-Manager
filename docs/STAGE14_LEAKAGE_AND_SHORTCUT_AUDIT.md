# Leakage и shortcuts

До fit зафиксированы5 predictors, linked acquisition split, exact-fingerprint isolation, unique sources/seed authority и отсутствие metadata в PacketSchema/FeatureSubset. Capture/session/device IDs,addresses/ports,scenario,labels/reasons,broker outcomes не входят в X. Изменение этих полей не меняет model input/prediction; malformed feature lists/identifier selection запрещены. Preprocessing fit толькоtrain, IF normal train only; thresholds и session aggregation validation-only проверены spy tests.

Честное ограничение порядка: количественные feature distributions/collision charts оформлены **после** завершения единственного holdout, только на train/validation, не использованы для изменения моделей/thresholds/features. Это descriptive post-evaluation audit, не притворный pre-test shortcut selection. В следующем исследовании такой полный descriptive audit следует завершить и зафиксировать до fit. Текущая матрица/агрегаторы были пререгистрированы раньше capture; holdout не использовался для выбора.

reports/stage14/leakage-audit.json явно записывает scope/time. Сохраняются equal-value/conflicting-label vectors, а не автоматическое объявление их duplicate packets. Постоянные TLS packet sizes,connection length,producer scheduling,client start staggering,PRNG seed family,shared host/window signatures и density of actor vs normal peers остаются возможными proxies. Bad-password length и allowed/forbidden topic length shortcuts не возвращены. Нет доказательства отсутствия всех shortcuts.

Ablations заранее заданы:all5,безframe.len,безdelta,безwindow,безflags,timing-only,size-only,дляRF/IF baseline. Все23 variants оценены одной frozen battery; никакой новой feature selection после test. All5 ablation повторяет baseline параметры намеренно и не считается independent run. Размерность меняет RF sqrt feature sampling; результаты не чистое causal feature-importance доказательство.
