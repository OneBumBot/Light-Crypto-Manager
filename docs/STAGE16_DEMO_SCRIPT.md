# Сценарий показа — 5–10 минут

Предпосылка: images уже собраны, fresh prepare либо безопасный resume выполнены по runbook. Сборка и provisioning не включены в обещанные 5–10 минут. Все действия только на собственном loopback demo.

1. **0:00–1:00 — система.** Войти Viewer, открыть Monitoring. Показать Alpha/alpha, Beta/beta, Gamma/gamma, свежую телеметрию, PG/Mongo и worker status. Это три программных Device Agent процесса.
2. **1:00–2:00 — защищённая передача.** Карточка Alpha: новые измерения, profile/epoch/sequence, Mongo history. Пояснить TLS+AEAD, PG admission и Outbox. Не выдавать старые строки за новое поступление.
3. **2:00–4:00 — ручное переключение.** Выйти защищённой POST-формой, войти Admin. Открыть «Криптография», Alpha. Запросить AES-128-GCM и подтвердить диалог. Показать PREPARE/READY, ACTIVATE/ACK и receipt новой telemetry. Дождаться текста «Криптопрофиль подтверждён новой телеметрией». HTTP202 и ACK не являются достаточным успехом.
4. **4:00–5:00 — обратное действие.** Вернуть Ascon, соблюдая штатный administrative rate limit. Дождаться новой verified telemetry. Показать, что Beta/Gamma не переключались; Gamma не предлагает AES.
5. **5:00–6:30 — Policy.** Открыть DRY_RUN: version, queue, readiness и processed-evidence freshness, причины/историю. UNKNOWN при отсутствующем ML допустим; рекомендация не применяется автоматически.
6. **6:30–7:30 — безопасный negative.** Войти Viewer/Operator и показать отсутствие переключения; автоматический smoke дополнительно подтверждает HTTP403/CSRF400/Gamma409. Не отправлять внешнюю нагрузку.
7. **7:30–8:30 — исследовательская граница.** Основной demo показывает Shadow unavailable, не fake scores. Если отдельно запущен разрешённый Stage15 stand, показать его реальный read-only RESEARCH/SHADOW_ONLY и trusted_detector=false, без утверждения о доказанной атаке. Отдельный research запуск не обязателен для основного показа.
8. **8:30–10:00 — итог.** Подтверждённый Ascon, новая реальная история, receipt IDs, independent Beta, manual-only control. Показать итоговую матрицу и ограничения. Затем штатный stop, без удаления state.

Не обещать «99% IDS», автоматическое обнаружение любых атак, надёжное ML-переключение, сертифицированную криптографию или промышленную готовность.
